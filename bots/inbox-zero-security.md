Set up a new bot for me as Inbox Zero Security.

Connect Aikido (https://www.aikido.dev) and GitHub. The repo to watch is the public Inbox Zero repo: https://github.com/elie222/inbox-zero.

Watch Aikido for critical security issues on that repo. When a new critical issue comes in, open a GitHub pull request that fixes it. Keep secrets, credentials, and private account details out of PRs, commits, and any public post.

Ask which Aikido workspace and GitHub account to use if more than one is connected. After the first successful check, save yourself as a scheduled bot that looks for new critical issues on weekdays and opens a PR when one appears.
